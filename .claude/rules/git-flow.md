# Reglas: git-flow

- Ramas: `feature/*`, `fix/*` desde `develop`; `release/*` desde `develop`; `hotfix/*` desde `main`.
- Conventional Commits; PRs obligatorios hacia `develop`/`main`; nunca force push.
- Sin `git push`, tags remotos ni releases sin autorización humana.
