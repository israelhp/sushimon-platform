# UI First

Analizar pantalla (skill `prototype-analysis`) → descomponer en componentes → fixtures/escenarios
(`mock-data-management`) → implementar con Server/Client Components → interacciones → accesibilidad →
validar visualmente contra el prototipo (`ui-ux-reviewer`).

## Prioridades

1. Fidelidad visual 2) reutilización 3) responsive 4) accesibilidad 5) buenas prácticas Next
2. separación presentación/datos 7) migración fácil a la API real.

## Prohibido

Arreglos enormes hardcodeados en componentes · red real (Supabase/PedidosYa/Neonet) · `localStorage` como auth.
