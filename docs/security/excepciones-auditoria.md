# Excepciones de la auditoría de dependencias

El CI ejecuta `pnpm audit --prod --audit-level high`. Una excepción se declara en `pnpm-workspace.yaml` (`auditConfig.ignoreGhsas`), es **temporal**, acotada a un solo advisory y debe tener justificación y condición de salida. Cualquier otra vulnerabilidad alta sigue rompiendo el CI.

## GHSA-fc5q-39xc-vjpf — `picomatch` ≤ 4.0.7 (ReDoS, severidad alta)

| Campo                | Detalle                                                                                                                                                                                                                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Alta de la excepción | 2026-11-18 (PR de CI; detectada al fallar el PR #27 y el CI de `develop`)                                                                                                                                                                                                                              |
| Problema             | Patrones extglob repetidos (`+(*)`, `+(*a)`) provocan retroceso exponencial y bloquean el event loop.                                                                                                                                                                                                  |
| Parche               | **Ninguno**: 4.0.7 es la última versión publicada y el advisory no indica versión corregida.                                                                                                                                                                                                           |
| Ruta                 | `sushimon-web > next-intl > @parcel/watcher > picomatch` (única; `pnpm why picomatch`).                                                                                                                                                                                                                |
| Por qué no aplica    | `@parcel/watcher` solo lo usa el extractor de `next-intl` (`SourceFileWatcher`), que arranca únicamente con `experimental.extract`. `sushimon-web/next.config.ts` no lo activa, así que `picomatch` no se ejecuta ni en producción ni en desarrollo. Los patrones los fija el proyecto, no el usuario. |
| Verificado           | Lectura del código de `next-intl@4.15.0` y de `next.config.ts`. No se ejecutó una prueba de que el watcher no arranca.                                                                                                                                                                                 |
| Condición de salida  | Quitar la excepción cuando exista `picomatch` > 4.0.7 (revisar con `pnpm audit --prod`). Revisarla antes si se activa `experimental.extract`.                                                                                                                                                          |
