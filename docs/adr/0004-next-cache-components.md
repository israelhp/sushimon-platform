# ADR-0004 Modelo de caché de Next

**Estado**: propuesta

El scaffold oficial de Next 16.4 activa `cacheComponents` y `partialPrefetching`; se **omitieron** en el bootstrap para no condicionar el modelo de datos antes de tener pantallas. Reevaluar en la Etapa 1 con el catálogo y el panel (datos por sucursal/usuario).
